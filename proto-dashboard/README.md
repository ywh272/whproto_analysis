# 프로토 승부식 분석 대시보드

베트맨 프로토 승부식 회차 화면을 **인쇄하기 → PDF로 저장**한 파일을 올리면,
과거 결과로 배당 흐름·팀별·종목/리그별·상대전적 통계를 만들고
현재 발매 중인 회차 경기를 과거 기준 적중 경향 순으로 정렬해 주는 웹 대시보드입니다.

- 서버 없이 브라우저에서만 동작합니다 (PDF는 브라우저 안에서 읽고, 데이터는 브라우저 IndexedDB에 저장).
- GitHub Pages로 무료 배포할 수 있습니다.

## 화면 구성

| 탭 | 내용 |
|---|---|
| 업로드·데이터 | PDF 업로드(여러 개 동시 가능), 회차 목록, 백업 내보내기/삭제 |
| 예측 분석 | 결과가 없는 회차의 상품별 적중 경향 점수, 배당 대비 우위, 기대회수, 배당 변동(▲▼) |
| 배당 흐름 | 배당 구간별 실제 적중률 vs 내재확률, 적중 배당 분포, 회차별 정배 적중률, 유형별 정배/역배/무 비율 |
| 팀별 | 승무패, 득실, 정배/역배일 때 승률, 핸디캡 성공률, 오버 비율, 최근 5경기 |
| 종목·리그별 | 홈승/무/원정승, 정배 적중률, 핸디캡 홈승, 오버, 홀 비율, 평균 합계 |
| 상대전적 | 두 팀 맞대결 기록과 상품별 적중 결과 |

## 접속 비밀번호

처음 접속할 때마다(새로고침·다시 열기 포함) 비밀번호를 입력해야 합니다. 비밀번호는 저장되지 않습니다.
비밀번호를 바꾸려면 `js/app.js`의 `PW_HASH` 값을 새 비밀번호의 SHA-256 값으로 바꾸세요
(`proto-dashboard:` + 비밀번호 문자열의 해시).

> 정적 사이트의 비밀번호 화면은 지나가는 사람을 막는 용도입니다. 코드를 직접 보면 우회할 수 있으니
> 민감한 정보는 저장소(`data/` 포함)에 올리지 마세요.

## 베트맨에서 바로 가져오기 (즐겨찾기 버튼)

1. 대시보드 **업로드·데이터** 탭의 주황색 **📊 프로토 보내기** 버튼을 브라우저 즐겨찾기 바로 끌어다 놓습니다.
2. 베트맨에서 **프로토 승부식** 회차 화면(진행 중 회차 또는 지난 회차 결과 화면)을 엽니다.
3. 즐겨찾기 바의 **📊 프로토 보내기**를 누르면 오른쪽 위에 작은 창이 뜹니다.
   - **이 회차 보내기**: 지금 보고 있는 회차의 경기·배당(결과가 있으면 결과까지)을 보냅니다.
   - **지난 회차 포함해서 보내기**: 입력한 범위의 지난 회차를 1.5초 간격으로 하나씩 불러와 함께 보냅니다(한 번에 최대 60회차).
4. 대시보드 창이 열리면 비밀번호를 넣습니다. 데이터는 자동으로 저장됩니다.

버튼은 베트맨 화면에 이미 받아져 있는 데이터를 읽는 방식이라 PDF보다 정확합니다.
수집 코드(`js/collector.js`)는 대시보드 저장소에서 불러오므로, 코드를 고쳐도 즐겨찾기는 다시 만들 필요가 없습니다.
베트맨 화면 구조가 바뀌면 동작하지 않을 수 있습니다. 그때는 PDF 업로드를 쓰면 됩니다.

## 사용 순서

1. **결과 PDF**(지난 회차, 맨 앞 칸에 결과가 있는 파일)를 한꺼번에 올립니다.
2. **예측 PDF**(현재 발매 중 회차)를 올립니다. 배당이 바뀌면 같은 회차 PDF를 다시 올리면 됩니다.
   회차·번호로 같은 상품을 찾아 배당 변동 이력을 쌓습니다.
3. 경기가 끝나면 그 회차의 결과 PDF를 올립니다. 예측 데이터에 결과가 합쳐지고 다음 분석에 반영됩니다.

파일 이름은 상관없습니다. 내용에서 회차와 결과 유무를 읽어 자동으로 구분합니다.

## 적중 경향 점수 계산 방식

각 선택지에 대해 아래 값을 가중 평균한 뒤, 선택지끼리 합이 100%가 되게 맞춥니다.

| 요소 | 가중치 | 설명 |
|---|---|---|
| 배당 내재확률 | 0.50 | 1/배당을 마진 제거해 정규화 |
| 과거 구간 적중률 | 최대 0.25 | 같은 종목·유형·배당순위·배당구간의 실제 적중률 (표본 10개 미만이면 전 종목으로 확대, 표본이 적을수록 가중치↓) |
| 팀 성적 | 최대 0.20 | 승무패: 홈팀 승률·원정팀 패율 등 / 핸디캡: 팀별 핸디캡 성공률 / 언오버: 두 팀 경기 합계가 기준선을 넘은 비율 |
| 상대전적 | 최대 0.05 | 같은 두 팀 맞대결 결과 |

표본이 적으면 배당 내재확률 쪽으로 당겨지도록 보정합니다. 데이터가 쌓일수록 과거·팀 요소의 비중이 커집니다.
**과거 통계는 경향일 뿐 결과를 보장하지 않습니다.**

## GitHub Pages 배포

1. GitHub에서 새 저장소를 만듭니다 (예: `proto-dashboard`, Public).
2. 이 폴더의 파일을 모두 올립니다. 웹에서 **Add file → Upload files**로 폴더 안 내용을 끌어 놓아도 됩니다.
   `index.html`이 저장소 최상위에 있어야 합니다.
3. 저장소 **Settings → Pages** 메뉴에서 Source를 **Deploy from a branch**, Branch를 `main` / `/(root)`로 저장합니다.
4. 1~2분 뒤 `https://<아이디>.github.io/proto-dashboard/` 로 접속합니다.

### 다른 기기에서 같은 데이터 쓰기

데이터는 접속한 브라우저에만 저장됩니다. PC와 휴대폰에서 같은 데이터를 보려면:

1. 업로드·데이터 탭 → **백업 내보내기 (JSON)** 로 `proto-data.json`을 받습니다.
2. 저장소의 `data/` 폴더에 `proto-data.json`으로 올립니다.
3. 데이터가 비어 있는 브라우저에서 사이트를 열면 자동으로 불러옵니다.
   또는 백업 JSON을 업로드 칸에 직접 끌어 놓아도 됩니다.

> 저장소가 Public이면 `data/proto-data.json`도 공개됩니다.

## 로컬에서 실행

```bash
python -m http.server 8000
# 브라우저에서 http://localhost:8000
```
(파일을 더블클릭해서 열면 모듈 로딩이 막히므로 간단한 서버로 여세요.)

## 파일 구조

```
index.html        화면 골격
css/style.css     스타일 (라이트/다크)
js/parser.js      프로토 PDF 파서 (pdf.js 사용)
js/collector.js   베트맨 화면에서 실행되는 수집기 (즐겨찾기 버튼이 불러옴)
js/betman.js      베트맨 데이터 → 대시보드 형식 변환
js/db.js          브라우저 저장소(IndexedDB), 회차·번호 병합, 배당 이력
js/stats.js       배당 흐름·팀·리그·상대전적·점수 계산
js/app.js         화면 구성
data/             (선택) proto-data.json 백업을 두면 자동 로드
```

## 지원 상품

승무패, 승패, 핸디캡(소수/세트 포함), 언더오버, SUM(홀짝), 승N패(농구 승5패), 전반 상품.
결과 칸의 스코어(핸디캡 적용 후 표기)와 합계로 적중 선택지를 계산합니다.
